## 三、规则 / 结构 / 格式（实测，含 3 个关键发现）

**① 左右双套结构**：`L*` 一套（`LFROMHN/LTOHN/ZIPL/PLUS4L/PARITYL/LFROMTYP/LTOTYP/ARIDL`）+ `R*` 一套（对应 `R*`）。**两侧并不总是都有** —— 左侧非空 81.09%、右侧 80.51%，即**约 19% 的记录只有单侧号段**，取值必须判空。

**② 同一 `TLID` 可以有多条记录**：`TLID` 唯一 9,939 < 记录数 11,072。实测 `TLID=68096613`（`Taraila Rd`）有 4 条，分别覆盖 200-298 / 18600-18608 / 18612-18676 / 18682-18698 等不同区间。
→ **号段匹配必须按 TLID 聚合，绝不能假设"一 TLID 一条"**，否则漏区间。

**③ 🔴 `PLUS4L`/`PLUS4R` 在这份 TIGER 2024 Kent 县数据里 0.00% 全空**（11,072 条一条都没有）。
四源核对：NAD `Plus_4` 也是 **0.00%**；Overture/OA 连 plus4 字段都没有。
→ **`plus4` / `zip9` 四个源目前都给不出来**，24 字段里的这两项必须改口径或留空，**不能用 TIGER 插值"造"出来**。

**④ 号段值格式**：字符串，多为纯数字，但混有字母前缀门牌与连字符区间 —— `A12`/`A4`/`A5`（左 60 条非纯数字）、`2048-99`/`2048-01`（区间），右字段 49 条非纯数字。奇偶 `PARITY ∈ {E 偶, O 奇, B, 空}`（B 极罕见：左 4、右 2）。

**⑤ `FULLNAME` 写法与其它三源都不同**：混合大小写 + USPS 缩写（`W Denneys Rd`、`S State St`）。同一地址三源四种写法实测对照：
| 源 | 形态 |
|---|---|
| NAD | `St_PreDir=West` + `St_Name=DENNEYS` + `St_PosTyp=Road` → `StNam_Full = "West DENNEYS Road"` |
| Overture | `street = "West Denneys Road"`（无法拆） |
| OpenAddresses | `STREET = "W DENNEYS RD"` |
| TIGER | `FULLNAME = "W Denneys Rd"` |
→ 归一化必须同时处理「全称↔缩写」「大小写」「方向词位置」三件事。

**⑥ 几何与坐标系（易踩）**：`.shp` shapeType=3（**Polyline**），顶点数 2~30，bbox 覆盖**整个 Kent 县** `(-75.754797, 38.831294) ~ (-75.324785, 39.347544)`；`.prj` = **GCS_North_American_1983（NAD83）**，而 NAD / Overture / OA 都是 WGS84 → **基准不同（本地区约 1 米级偏移）**，空间匹配必须给容差。

**⑦ 边界图层结构统一**：全为 `esriGeometryPolygon` + `rings` 数组（外环 + 内环，Dover 市 32 环），`spatialReference.latestWkid=4326`。关键锚点实测（REST 与 shapefile 双通道互验一致）：

## 五、对 24 字段合并的结论（供 Gemini 参考）

1. **TIGER 不是"地址源"，是"号段校验器"**：只给"哪条路 / 两边门牌从几到几 / 奇偶 / 邮编"，不给点坐标。S/A 级的 "valid within TIGER boundary/road range" 只能实现成：**把 NAD/OA 的门牌点投到附近路段，判断门牌是否落在 `[LFROMHN,LTOHN]` 或 `[RFROMHN,RTOHN]` 内且奇偶匹配**。
2. **号段匹配必须按 TLID 聚合 + 允许单侧**：TLID 9,939 个但记录 11,072 条（同段多区间），约 19% 只有单侧号段；且存在 `LFROMHN > LTOHN` 的降序区间（#5/#6）→ 判区间要用 `min/max`，不能假设升序。
3. **`plus4`/`zip9` 四源全部拿不到**（TIGER `PLUS4L/PLUS4R` 0%、NAD `Plus_4` 0%、Overture/OA 无此字段）→ 24 字段表中这两项必须留空或改口径，**验收标准必须修改**。
4. **空间校验要给容差**：TIGER 是 NAD83、其余三源是 WGS84，加上各源精度差异（OA 4~7 位小数 vs NAD/Overture 14 位）→ **建议阈值 30~50 米**（同一个 5921 W Denneys 在 NAD 与 OA 之间只差不到 1 米，30 米足够宽松又不会误配）。
5. **行政字段锚点已确认可用**：`county_fips=10001`、`place GEOID=1021200`、`state_fips=10`、`state STUSAB=DE`、`ZCTA5=19901/19904`（REST 与 shapefile 双通道互验一致）。
