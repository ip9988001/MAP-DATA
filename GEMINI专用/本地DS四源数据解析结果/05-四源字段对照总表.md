## 6. 关键结论与坑（合并前必须知道）

1. **Overture ≈ NAD，不是独立源** → `source_confidence` 不能把二者当两条独立证据，否则同一份 NAD 数据被重复计数。
2. **`plus4`（#18）四源全部拿不到**：NAD `Plus_4` 全空、TIGER `PLUS4L/PLUS4R` 全空、Overture 与 OA 根本没有该字段 → **`zip9` 只能退化为 `zip5`**。
3. **`building_floor`（#9）与 `house_number_suffix`（#2）无任何来源**，建议直接从黄金表删除或长期置 null。
4. **`addr_type`（#21）名义有值但无信息量**：NAD 的 `Addr_Type` 在本批 100% 为 `Unknown`，`Placement` 同样全 `Unknown`。
5. **只有 NAD 原生拆好了街道**（`St_Name`/`St_PosTyp`/`St_PreDir`/`St_PosDir`）；Overture、OA、TIGER 的街道都是**一整串**，需正则拆解，且**方向词粒度不一致**（NAD/Overture 全拼 `South`，OA/TIGER 单字母 `S`）。
6. **街道类型后缀缩写不统一**：NAD 全称（`Street`/`Road`）、Overture Title Case 全称、OA 缩写（`RD`/`DR`，混有全称）、TIGER 缩写（`Rd`/`St`）→ 合并前必须归一化。
7. **`unit` 有脏值**：OA 的 `UNIT` 存在字面字符串 `<Null>`（kent 112 条），Overture 也有 1 条 `<Null>`。
8. **`city_of_dover.csv` 缺 CITY/POSTCODE**（均 0%）→ 多佛本体的城市与邮编要靠空间落点或 `kent.csv` 补齐。
9. **`TLID` 不是唯一键**（11,072 行 / 9,939 个 TLID），TIGER 号段区间判断时**不能假设 FROMHN < TOHN**（存在降序，如 `8698→8618`）。
10. **4 个 `.geojson` 边界文件是 Esri JSON**（`attributes` + `geometry.rings`），不是标准 GeoJSON，解析方式不同。
11. **TIGER 与另三源性质不同**：TIGER 是道路号段 + 行政多边形，**不能直接当点地址参与合并**，只能做空间关联（补邮编/行政码/道路等级）。
12. **数据时效差异大**：NAD 2025-09、Overture 2026-09（实为 NAD 快照）、OA 2021-10、TIGER 2024 → 同址冲突时建议按 **NAD > TIGER > Overture > OA** 取值（Overture 与 NAD 同源，优先级等同）。

## 7. 建议的最终取值优先级（Coalesce）

```
house_number      : NAD.Add_Number      → OA.NUMBER      → (TIGER 区间校验)
house_number_suffix: (无源，置 null)
street_full       : NAD.StNam_Full      → Overture.street → TIGER.FULLNAME → OA.STREET
street_name/type  : NAD.St_Name/St_PosTyp → 从 street_full 正则拆解
street_pre_dir    : NAD.St_PreDir       → 从 street_full 拆解并统一为全拼
street_post_dir   : NAD.St_PosDir       → 从 street_full 拆解
unit              : NAD.Unit(=SubAddress) → OA.UNIT → Overture.unit
building_floor    : (无源，置 null)
postal_city       : NAD.Post_City       → Overture.postal_city → OA.CITY
municipal_city    : NAD.Inc_Muni        → TIGER.place 空间落点
county_name/fips  : TIGER.county_kent (Kent County / 10001)
state_abbr/name/fips: TIGER.state_de (DE / Delaware / 10) → NAD.State 校验
zip5              : NAD.Zip_Code → Overture.postcode → OA.POSTCODE → TIGER.ZIPL/ZIPR
plus4             : (无源，置 null)
zip9              : zip5（退化）
lat/lon           : NAD.Latitude/Longitude → Overture.geometry → OA.LAT/LON
addr_type         : 需自建规则推断（NAD 全 Unknown）
area_code/timezone: 映射表 (302 / America/New_York)
source_confidence : 按「NAD 与 Overture 合并计 1 票」统计
```
